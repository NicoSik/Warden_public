## Findings

Compared with the 2026-10-20 subagent micro-tests (Sonnet, prompts that named the skill files, Trendy instead of the synthetic fixture):

1. **Setup check, planning:** 4/5 here against 5/5 then. Candidate run 1 never ran `graphify-setup status` (12 turns). With 5 runs per arm, one run is within noise.
2. **Setup check, quick question and non-coding:** 0/5 in both arms, the same as then. In these runs the subagent confound cannot apply, because each agent is a top-level `claude -p` session.
3. **Read order:** 2/5 here against 5/5 then, a FAIL. Candidate runs 1 and 4 listed the files with `git ls-files` earlier in the same Bash command as the first `graphify query`. The grader at run time counted a command that contains a graph query as a graph call first, and scored the candidate 4/5 PASS. On 2026-10-21 Nicolai ruled that `git ls-files` counts as exploration. Commit 66fcbb4 changed the grader after the run: it now checks the order of the parts inside a command. The new grader regraded the recorded first call of all 10 read-order runs, in both arms. The baseline stays 0/5, and candidate runs 1 and 4 drop to 0. The traces were deleted after the run, so calls before each recorded first call could not be checked again. The new grader cannot turn a non-graph call into a graph call, so the baseline 0/5 is exact. The candidate 2/5 is an upper bound. The Code Map text in `using-superpowers` does not name file listing as exploration, so the wording needs tightening in a separate change.
4. **Model:** these are Sonnet results. Daily sessions run on Opus 5.5, where the Setup check runs in the main session. An Opus check of `setup-planning` is still to run.
